# Luobozi Schedule release feed

This public repository contains the anonymous, read-only update manifest used by Luobozi Schedule clients.

- Manifest: https://raw.githubusercontent.com/jk1420/luobozi-release-feed/main/latest.json
- Source releases: https://github.com/jk1420/win11_desktop_scheduled/releases

The source application repository may remain private. The manifest is public so clients can discover versions without GitHub credentials; release pages and attachments still follow the source repository's access policy.
